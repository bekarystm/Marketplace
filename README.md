# Marketplace

Маркетплейс доставки продуктов из супермаркетов (Талдыкорган).

## Состав
- `apps/client` — клиентское приложение (Expo, iOS/Android)
- `apps/partner` — приложение для курьеров и сборщиков (Expo)
- `apps/admin` — веб-админка и кабинет магазина (Next.js)
- `supabase/` — схема БД, миграции, Edge Functions
- `packages/` — общие типы, UI, i18n (ru/kk)

## Стек
Expo (React Native, TypeScript) · Next.js · Supabase (Postgres, Auth, Realtime, Storage, Edge Functions) · OpenStreetMap/MapLibre · Expo Push · EAS Build
